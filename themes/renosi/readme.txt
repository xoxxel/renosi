قالب فروشگاهی رنوسی — مخصوص فروشگاه قطعات یدکی خودرو، سازگار با ووکامرس.

== نصب ==

۱. پیشخوان وردپرس ← نمایش ← پوسته‌ها ← افزودن ← بارگذاری پوسته ← فایل renosi.zip
۲. پوسته را فعال کنید. افزونه‌ی ووکامرس باید نصب و فعال باشد.
۳. پیشخوان ← تنظیمات ← پیوندهای یکتا ← یک‌بار «ذخیره» بزنید.

== راه‌اندازی سریع ==

بعد از فعال‌سازی، به «نمایش ← راه‌اندازی رنوسی» بروید و «ساخت محتوای نمونه» را بزنید.

== راه‌اندازی صفحه‌ی اصلی ==

۱. یک برگه با نام «خانه» بسازید (محتوا لازم نیست).
۲. تنظیمات ← خواندن ← «یک برگه‌ی یکتا» ← صفحه‌ی نخست: خانه.
۳. نمایش ← سفارشی‌سازی ← «تنظیمات قالب رنوسی» برای بنر، بخش‌ها، رنگ، اطلاعات تماس و شبکه‌های اجتماعی.

== اسلایدر بنر ==

سفارشی‌ساز ← تنظیمات قالب رنوسی ← صفحه‌ی اصلی — اسلایدر بنر.
برای هر اسلاید تصویر (پیشنهاد ۱۸۰۰×۹۵۰)، عنوان، توضیح، متن دکمه و لینک دارید.
اگر متن داخل خود تصویر است، عنوان را خالی بگذارید تا کل بنر لینک شود.
اسلایدی که نه تصویر دارد نه عنوان نمایش داده نمی‌شود.

== ارسال ۳ ساعته تهران ==

سفارشی‌ساز ← تنظیمات قالب رنوسی ← ارسال ۳ ساعته تهران: متن بدج و توضیح.
برای هر محصول: ویرایش محصول ← تب «حمل‌ونقل» ← تیک «ارسال ۳ ساعته تهران».
برای چند محصول با هم: فهرست محصولات ← ویرایش گروهی ← «ارسال ۳ ساعته».
یا گزینه‌ی «نمایش برای همه‌ی محصولات موجود» را روشن کنید.
در صفحات فروشگاه دکمه‌ی «فقط ارسال ۳ ساعته» برای فیلتر کردن نمایش داده می‌شود.

== سرعت و سرور ==

قالب در حالت عادی فایل‌های فشرده‌ی ‎.min را بارگذاری می‌کند. اگر فایل اصلی (مثلاً main.css) را ویرایش کنید،
چون جدیدتر از نسخه‌ی ‎.min است، خودکار همان فایل ویرایش‌شده استفاده می‌شود.
برای امتیاز بالا روی سرور واقعی: فشرده‌سازی gzip/brotli و کش طولانی برای فایل‌های ثابت را فعال کنید
و یک افزونه‌ی کش صفحه (مثل LiteSpeed Cache یا WP Super Cache) نصب کنید.
Lighthouse را در پنجره‌ی ناشناس (Incognito)، بدون ورود به پیشخوان و با حالت «به‌زودی» ووکامرس خاموش اجرا کنید.

== سئو ==

قالب بدون افزونه هم توضیحات متا، canonical، Open Graph و اسکیمای لازم را تولید می‌کند.
اگر Yoast، Rank Math، AIOSEO یا SEOPress نصب باشد، قالب این بخش‌ها را به افزونه می‌سپارد
و فقط اسکیمای تکمیلی محصول (کد فنی، برند، خودروهای سازگار) را اضافه می‌کند.
توضیحات دسته‌بندی‌ها و خودروها (متن سئو) زیر محصولات و به صورت «بیشتر بخوانید» نمایش داده می‌شود.

== جستجوی قطعه بر اساس خودرو ==

محصولات ← خودروها:
- ابتدا برند را بسازید (مثلاً «رنو»)، بدون مادر.
- سپس مدل‌ها را با مادرِ همان برند بسازید (مثلاً «تندر ۹۰» با مادر «رنو»).
- در صورت نیاز تیپ/موتور را زیرمجموعه‌ی مدل بسازید (مثلاً «تیپ ۵» با مادر «پژو ۲۰۶»).
  قطعاتی که به مدل اختصاص داده شده‌اند در صفحه‌ی همه‌ی تیپ‌های آن مدل هم دیده می‌شوند.
- برای هر برند لوگو بارگذاری کنید (در صورت نبودن لوگو، حرف اول نام نمایش داده می‌شود).
- در صفحه‌ی ویرایش هر محصول، خودروهای سازگار را تیک بزنید.
- یک برگه با قالب «برندهای خودرو» بسازید تا فهرست کامل برندها و مدل‌ها نمایش داده شود.
فرم «قطعه‌ی خودروی خود را پیدا کنید» در صفحه‌ی اصلی، تب «خودروهای سازگار» در صفحه‌ی محصول
و آدرس‌هایی مثل /vehicle/renault/tondar-90/ به صورت خودکار فعال می‌شوند.

== کد فنی (SKU) ==

کد فنی همان «شناسه‌ی محصول (SKU)» ووکامرس است. روی کارت محصول و صفحه‌ی محصول نمایش داده می‌شود
و جستجوی سایت، کد فنی را هم جستجو می‌کند (اعداد فارسی هم پذیرفته می‌شوند).

== منوها و ابزارک‌ها ==

نمایش ← فهرست‌ها: منوی اصلی، منوی نوار بالا، فوتر ستون اول و دوم.
نمایش ← ابزارک‌ها:
- «سایدبار فروشگاه (فیلترها)»: فیلترهای ووکامرس (دسته‌بندی، قیمت، ویژگی‌ها). در موبایل کشویی است.
- «فوتر — نمادهای اعتماد»: کد اینماد / ساماندهی را با ابزارک «HTML سفارشی» قرار دهید.
- «سایدبار وبلاگ».

== برندها ==

اگر از ووکامرس ۹.۶ به بعد استفاده می‌کنید، از «محصولات ← برندها» برند و لوگو تعریف کنید
تا نوار برندها در صفحه‌ی اصلی و برند در صفحه‌ی محصول نمایش داده شود.

== سبد خرید و تسویه حساب ==

هم برگه‌های بلوکی جدید ووکامرس و هم شورت‌کدهای کلاسیک ([woocommerce_cart] و [woocommerce_checkout])
استایل‌دهی شده‌اند. بیشتر درگاه‌های پرداخت ایرانی با تسویه حساب کلاسیک بهتر کار می‌کنند.

== ویژگی‌ها ==

* سیستم دیزاین با متغیرهای CSS (رنگ، فاصله، شعاع گوشه، سایه، تایپوگرافی)
* فونت وزیرمتن داخل قالب (بدون وابستگی به گوگل فونت)، با گزینه‌ی اعداد فارسی
* کاملاً راست‌چین و ریسپانسیو، سربرگ چسبان، منوی کشویی موبایل و نوار ناوبری پایین
* سبد خرید کشویی با به‌روزرسانی AJAX
* کارت محصول با درصد تخفیف، کد فنی و دسته
* دکمه‌های +/- تعداد، تب خودروهای سازگار، فهرست اعتماد در صفحه‌ی محصول
* انیمیشن‌های کوتاه و ملایم؛ احترام به تنظیم «کاهش حرکت» سیستم‌عامل
